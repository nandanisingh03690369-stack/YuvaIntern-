## How to Run
```bash
git clone https://github.com/<your-username>/ds-internship-yuvaintern.git
cd ds-internship-yuvaintern
pip install -r requirements.txt

# 1. Download datasets from Kaggle into /data (see data/README.md)
# 2. Run any task from inside its folder:
cd week1_eda
python eda_titanic.py
```
Generated plots are saved in an `outputs/` folder inside each week's directory.
